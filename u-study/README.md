# U Study 使用说明

U校园课程与学习工作台，当前版本 **1.4.30**。在 Windows 本地运行，通过 Playwright 控制独立的 Edge / Chrome 窗口，无需浏览器扩展。

完整变更和升级步骤见 [更新日志与发布报告](CHANGELOG.md)。

## 启动与退出

推荐从 [GitHub Releases](https://github.com/codezjj777/UCampus/releases/latest) 下载 Windows x64 ZIP，完整解压后双击最外层的 `一键启动.cmd`。便携版包含 Node.js 与生产依赖，电脑需要已安装 Edge 或 Chrome。

源码用户需要 Node.js 20.19+，在本目录运行：

```powershell
npm.cmd ci
npm.cmd start
```

本地工作台：[http://127.0.0.1:4173/](http://127.0.0.1:4173/)。启动器等待后台就绪后打开工作台和专用窗口。重复启动复用服务、窗口并保留活动任务。退出时点击左下角「安全退出」：停止答题和学习时长任务，保存记录、关闭专用学习窗口，确认后台退出后结束。也可双击 `一键停止.cmd`，或运行 `npm.cmd stop`。关闭终端或网页不会停止后台；重启电脑后需重新启动。

修改源码后，启动器会核对后台实际加载的代码，即使版本号相同也会识别旧进程。空闲后台会安全重启；有任务或专用窗口时会提示先退出，保留当前操作。

不要直接打开 `dist/index.html`。连接短暂中断会自动重读状态，保留表单；已提交操作需要检查后手动重试。

## 第一次使用

1. 点击「连接 U校园 → 打开 U校园登录」，在专用窗口正常登录并完成验证码。
2. 回工作台点击「同步课程」。同名教材按课程、班级和记分周期分别保存。
3. 在「答题设置」配置题库或 AI 并保存。查看课程和目录不需要答案来源。
4. 从课程卡片进入「自动答题」，选择单元，读取目录并核对必修、完成和待处理数量。
5. 点击「开始自动答题」，逐项处理所选单元必修且未完成的项目。
6. 默认最终提交前等待人工核对。检查专用窗口中的答案，手动提交后点击「继续核对」。自行启用「自动提交并进入下一页」后，程序会按设置点击提交，可能影响平台课程成绩。
7. 只有平台目录确认完成后才继续；不支持、材料不足或无法识别的项目需要手动处理。

初始示例标记为演示数据，连接并同步后显示真实课程。

## 答案来源

### 本地题库

导入 JSON 文件，格式见 [question-bank.example.json](dist/question-bank.example.json)。匹配核对题干、材料、题型、选项和空位，支持选项乱序；冲突或缺少答案时不会随机填答。

平台明确确认整道大题全对、且目录确认完成后，保存完整题目和实际提交答案。可通过「导出完整题库」查看。发布包不含个人已有题库。

### AI 辅助

启用「AI 补充答题」，输入服务商提供的**完整 HTTPS Chat Completions 接口地址**、模型名称和 API Key。「测试连接」测试当前输入，无需先保存；测试不会保存临时 Key，点击「保存设置」后才落盘。

再次打开设置时 Key 框留空，仅显示保存状态。同一接口留空可沿用已保存 Key，换接口需填写对应的新 Key。图片及视频画面需要识图模型。

启用 AI 会把题干、选项及相关文字、转写或图片发送到配置的服务商，不发送 U校园密码或 Cookie。答案需要核对，API 由所选服务商计费。

进入题目后会先检查并关闭学习时间提示；等待 AI 时也会持续检查新弹出的提示。AI 请求每 15 秒报告等待阶段，返回后记录本次耗时。每次请求最多等待 120 秒，可恢复故障最多尝试 3 次；停止任务会取消当前请求。

学习提示关闭后若残留独立遮罩，程序确认其所属弹窗已关闭后会继续当前填写操作，保留已生成答案。题页处于后台或 iframe 中也适用；仍显示的其他确认弹窗继续等待核对。

题目上方的 Directions 会作为独立要求随题干、材料和词库发送给 AI，包括位于嵌套内容区外的公共要求。选词填空若要求填写大写字母，程序会保留字母与单词的对应关系，并在填写前校验字母格式及禁止重复的要求；AI 返回单词时按页面词库转换成对应字母。

左侧阅读材料中的普通表格也可作为词库：按题目指定字母范围完整读取显式标号，不按单元格位置猜字母。操作中断时，日志保留登录窗口关闭、操作超时等实际原因，避免只显示通用英文取消错误。

自主造句题使用专门提示词，依据题目要求和 Notes 生成完整示例句，每个作答框对应一个答案。空答案、数量不符或句型不符时，会在请求次数上限内补请求一次；按需依赖原文、音频或图片的事实题仍须具备对应材料。

## 听力与口语

听力优先读取原文和字幕；缺少可靠文本时可使用本地语音识别。视频视觉题可通过本地 PyAV 组件抽取画面。

需要这些可选组件时，先安装 **Python 3.10–3.13**，再双击 `准备听力识别.cmd`，或运行 `npm.cmd run setup:speech`。首次下载组件和约 148 MB 的 `base.en` 模型，完成后重启。失败可检查网络后重试；自定义 Python 用 `USTUDY_PYTHON` 指定。

已适配的标准个人录音支持短录音和完整复述；完整复述需要 AI 及 Windows 英文语音。部分分角色对话另有处理流程，其他口语和自定义控件仍可能需要手动处理。完成状态以平台目录为准。

## 支持范围

- 课程同步、详情、按单元读取必修目录和进度刷新。
- 已适配的单选、多选、判断、普通及下拉填空、简答、翻译和写作。
- 已适配的句子、段落主旨、交际功能配对和看图题。
- 已适配的词卡、视频和听力材料处理，部分口语和讨论板任务。
- 只有音频且没有作答控件的项目：拖至结束前约 1 秒后播放，等待自然结束；末尾意外暂停时从原位置续播一次，最后核对目录完成状态。
- 多页题目、暂停/恢复/停止、人工核对和本地题库积累。

不同教材模板不同，以上不代表支持所有页面。材料、选项不完整或页面变化时暂停核对。教材进度读取平台课程卡片，不用单元完成数推算整本书完成。

## 数据保存与备份

| 位置（相对于本目录） | 内容 |
| --- | --- |
| `.runtime/state.json` | 课程、任务与设置 |
| `.runtime/bank-*.json` | 本地题库 |
| `.runtime/credentials.json` | 与接口绑定的 API Key，当前为本机明文 |
| `.runtime/browser-profile/` | 专用浏览器登录资料 |
| `.runtime/speech/` | 可选语音组件与模型 |
| `.runtime/server.log`、`server-error.log` | 后台运行与错误日志 |
| `.cache/` | 依赖、构建及测试缓存 |

`.runtime/` 属于个人资料，整体被 Git 和发布脚本排除，不要上传或分享。排错分享日志前也需去除账号、题目和密钥等内容。

更新前先停止程序，备份整个 `.runtime/`，把新版解压到新目录，再将旧版 `.runtime/` 复制到新版相同位置。不要同时启动两个副本使用同一份数据。

## 可选环境变量

一般使用设置页面即可。需要覆盖时在启动程序的终端设置：

| 变量 | 用途 |
| --- | --- |
| `PORT` | 本地端口，默认 4173，范围 1024–65535 |
| `USTUDY_BROWSER` | `msedge` 或 `chrome` |
| `USTUDY_API_KEY` | 覆盖已保存 Key |
| `USTUDY_API_ENDPOINT` | 完整 HTTPS 接口 |
| `USTUDY_API_MODEL` | 模型名称 |
| `USTUDY_PYTHON` | 可选组件使用的 Python 路径 |

环境变量在后台启动时读取，变更后需重启。环境变量 Key 应同时配置对应接口，不会转发到网页临时切换的其他接口。服务只监听本机 `127.0.0.1`，无需部署远程工作台。

## 故障排查

- **启动失败**：确认完整解压、Edge / Chrome 已安装，查看 `.runtime/server-error.log`。源码用户检查 Node.js 版本和依赖安装。
- **端口冲突**：设置其他 `PORT` 后启动，停止时使用相同端口。
- **课程缺失**：确认登录的是专用窗口，等待平台加载后重新同步。
- **AI 失败**：检查完整接口、模型权限、Key、额度和网络；看图需要识图模型。
- **等待核对**：按日志检查弹窗、材料和答案，处理后点击「继续核对」。
- **模板改版**：「答题设置 → 页面适配设置」可填写题目容器、下一题及提交按钮的 CSS 选择器，错误配置会停止任务。
- **听力准备失败**：确认 Python 版本，检查终端输出，网络恢复后重试。
