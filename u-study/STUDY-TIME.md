# 自动学习时长

每张真实课程卡片的「自动答题」旁提供「自动学习时长」。点击后进入左侧同名功能区，并选中该课程。也可以从左侧直接进入。

1. 直接复用自动答题的 U校园窗口和登录状态。点击「显示 U校园窗口」只显示现有窗口；尚未打开时使用原有配置打开一个窗口。已登录时无需再次登录。
2. 选择课程并「读取单元」，再选择单元和学习页面。优先选择 Learning objectives / 学习目标，已完成项目也可选择。
3. 设置 1～1440 分钟的目标，点击「开始自动学习」。
4. 本地后台运行时，可以切换功能区或关闭工作台。电脑休眠、后台服务关闭期间的时间不计入驻留。

「本次驻留」累计可正常读取的学习页面的驻留时间，界面以秒连续更新。界面在后台最近确认的计时点之间平滑显示；暂停、结束、断线或计时点过期时停止推进，不补算退出及休眠时间。它是本机记录，不代表平台已经确认的有效时长。

「平台新增时长」和「平台累计时长」优先使用学习页面的明确已学时长；Learning objectives 等页面未显示时长时，自动从「综合成绩 → 必修学习时长 → 查看详情」读取同班级、同记分周期下所选教材的必修学习时长，每 2 分钟核对一次。累计与新增都按「时:分:秒」显示，读取成功前保持上次确认值。任务使用该教材的时长，课程列表上方另行显示全部教材合计。任务启动时重新读取基准，不使用旧缓存或本机驻留时间代替平台确认值；暂停、重启后继续会保留原基准及统计范围。

成绩查询在独立的后台流程中进行，不阻塞学习页检查、保活和驻留累计，也不因查询耗时而报告休眠。真正休眠、时钟跳变或本机计时中断时仍会排除对应时段。

成绩核对使用同一 U校园窗口的临时后台标签页，学习页面保持原位；遇到正在进行的自动答题操作，会暂缓核对并在空闲后重试，界面显示上次确认值和等待原因。综合成绩可能延迟更新，连续核对 20 分钟无增长、读数减少或统计范围变化时进入待核对。首次读取失败时也会保留任务，可处理原因后点击「继续学习」。只使用明确的已学数据，不把要求时长或其他教材时长计入当前任务。

默认每 20 分钟向当前学习页发送一次普通鼠标移动，同时持续检测停计时提示。已适配真实提示「由于你长时间未操作，请点确定继续使用。」及其自定义弹层和「确定」按钮；学习页和课程首页均会检查。课程首页只确认这一完整提示，答题页、答题正在进行时及受保护页面不会被此流程操作。单元学习时间说明也可正常确认；其他提示或不唯一的按钮留待手动处理。

确认停计时提示后会立即重新核对平台时长，保持原任务基准。确认之前已在途的成绩响应不会用于判定达标，随后重新读取。停计时的间隔不计入本机驻留；平台确认新增仍以实际平台读数为准，不补造暂停期间的时长。

「暂停」会离开当前学习页，继续时重新载入并核对；「停止」或达到目标会关闭本功能的学习页。包含作答控件、地址变化或学习内容变化的页面不会继续累计。重新启动后台后，未结束的记录显示「等待继续」，继续时重新核对页面，不补算退出期间的时间。

学习记录仍保存在 `.runtime/study-time/state.json`，与答题任务、题库及答题设置分开保存。浏览器复用原有的 `.runtime/browser-profile/`，不再启动单独的学习浏览器配置。学习内容在同一窗口的独立标签页中打开，平台要求新开窗口的学习链接也会留在该学习标签页。

学习功能只关闭、暂停自己的标签页；课程首页仅处理上述完整停计时提示，答题页及其他页面保留。不会修改整个浏览器的默认设置，也不会给答题页安装提示处理。读取课程目录时使用已有操作协调机制，答题或课程读取正在进行时先等待其结束，避免争抢页面。已打开的学习标签页可以独立暂停、继续和停止。

学习页跳转时会等待内容稳定后再开始计时，页面初始化引起的网址片段更新不会误停。课程地址参数和正文仍会核对，真正切换教材或学习内容时会保留页面并等待人工核对。停在首次加载阶段的任务可继续读取最终页面，无需重复打开标签页。

更新后应在原有答题任务结束时，先停止再重新启动后台，加载新接口。只刷新网页不会让旧后台加载新增模块。

独立验证：`npm.cmd run test:study-time`、`npm.cmd run test:study-time:browser`。原有测试和构建命令继续可用。
# 课程学习时长进度

「我的课程」在课程进度下方显示学习时长进度、平台已学时长；列表上方显示当前记分周期内同班级各本教材的时长合计。

窗口已登录且自动答题空闲时，工作台会从「综合成绩 → 必修学习时长 → 查看详情」读取当前学期的数据。读取在原 U校园窗口的临时后台标签页中完成，读完关闭该标签页；不会切换正在学习、答题或手动打开的页面。也可以点击卡片上的「读取 / 刷新」，手动更新对应班级和记分周期的全部教材。

进度条使用详情里的「百分制得分」，已学时长使用详情里的「必修学习时长」；没有明确要求时长时，不根据得分反推达标小时数。合计来自同一份完整明细，不重复相加课程卡片；同名教材按班级和记分周期区分。读不到数据时保留上次结果及更新时间，不显示虚假的零时长。平台时长缓存单独保存在 `.runtime/study-time/progress.json`。
