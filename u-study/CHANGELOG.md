# 更新日志与发布报告

## v1.4.30 · 2026-11-05

本次将本地累计更新统一发布为 v1.4.30，与 GitHub 上一版 v1.4.20 比较。中间的本地版本不单独补发 Release。

### 使用体验与退出

- 新增工作台「安全退出」入口：停止任务、保存数据、关闭学习窗口后等待后台真正退出；失败时可以重试，退出过程中阻止继续操作及自动重连。
- 工作台显示后台实际版本号和最后修改日期，便于确认正在使用哪一版。
- 启动器除版本号外还核对源码构建摘要，识别“文件已更新，但后台仍运行旧代码”的情况；存在任务或登录窗口时提示先正常退出再重启。

### 音频、视频与学习恢复

- 新增纯音频项目处理，支持已适配播放器的进度条定位和末尾播放，等待音频自然结束及平台目录确认完成。
- 兼容音频实际结束点与声明时长的微小差异；末尾意外暂停时只从原位置续播一次。包含答题控件、录音任务、多播放器或不可靠媒体状态的页面继续交由对应处理器或人工核对。
- 抽出音视频共用的播放流程，统一任务取消、播放状态检查和目录完成确认。
- 学习任务暂停、网络异常或待核对后恢复时，等待正文和页头连续稳定；消除重复标题、初始化空白造成的误报，保留原任务的时长基准，恢复等待期间不累计驻留。

### 题目识别与答案处理

- 将 Directions 独立读取并随题干、材料和词库发送给 AI，兼容嵌套内容区外的公共要求。
- 选词填空保留显式字母与单词对应关系，支持左侧阅读材料中的表格词库；要求大写字母时可将模型返回的单词转换为对应字母，并校验答案数量和禁止重复的要求。
- 题目要求纳入题库匹配和页面签名，降低相同题干但作答要求不同的答案误用风险。
- 自主造句使用专门提示词，根据 Directions 和 Notes 为每个答案框生成完整示例句；空答案、数量错误或句型不符时，在请求上限内补请求一次。依赖原文、音频或图片事实的题目仍需具备材料。

### 稳定性与日志

- 进入题页、等待 AI、填写及提交前持续处理已识别的学习时间提示；提示已关闭后核对独立残留遮罩，保留已经生成的答案继续处理。其他仍可见的确认弹窗继续等待人工核对。
- AI 请求按阶段显示等待进度与耗时；每次请求最多等待 120 秒，可恢复故障最多尝试 3 次，停止任务会取消当前请求。
- 操作中断日志保留窗口关闭、超时等实际原因，减少含糊的英文取消提示。

### 下载与升级

下载 Release 的 `U-Study-1.4.30-windows-x64.zip`，完整解压后双击「一键启动.cmd」。Windows x64 便携版内置 Node.js 和生产依赖，仍需电脑已有 Edge 或 Chrome；可选听力识别仍需 Python 和单独准备模型。

更新前先安全退出并备份旧版的 `u-study/.runtime/`。将新版解压到新目录，需要保留个人设置和记录时，将备份复制到新版同一位置再启动。不要让两个副本同时使用同一份数据。

源码和发布包排除个人登录资料、API Key、课程记录、真实题库、运行缓存和日志。当前版本的已保存 Key 仍为本机明文配置。
